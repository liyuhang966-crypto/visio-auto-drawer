# 通用绘图经验

- 中文字体应同时设置 `Char.Font` 和 `Char.AsianFont`，检查 Visio 主题回退与字形差异。
- 标题和正文应使用分离的安全区域，多行文本应检查行距与留白。
- 复杂参考图先标定区域与连接通道，再绘制；不能使用占位预设声称已识别布局。
- 背景容器与子节点的语义包含关系不等于碰撞；应复核实际字形范围。
- 原图没有图例时不应添加无意义图例，应记录检查适用性。
- PNG 导出需复核页面比例、白边与箭头边界。
- 只有输出与检查均有效时才可报告完成。

这里仅保存去除案例名称、时间戳和图纸内容后的通用经验。用户案例运行记录应保留在本地被忽略的输出目录。
