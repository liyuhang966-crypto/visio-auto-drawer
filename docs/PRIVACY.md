# 发布与隐私说明

本公开版本通过文件白名单从本地 skill 整理：仅保留 Python 源码、SKILL.md、界面配置与通用 JSON 示例，并补充安装说明、启动脚本、依赖清单和许可证。

未发布：

- Python 编译缓存、虚拟环境、本机配置及原有 Git 历史。
- 本地案例运行日志、案例标识与时间戳记录。
- 用户的参考图、私有研究图纸、裁剪素材、生成的 Visio 文件与会话输出。
- 与具体历史项目绑定的架构示例。

可移植性处理：

- 移除对固定父目录层级的依赖，默认项目目录为当前工作目录，也支持显式 `--project-root`。
- 失败记录写入项目内 `output/lessons/`，由 `.gitignore` 排除。
- 提交使用 GitHub noreply 地址，不包含个人邮箱或 Windows 用户名。

发布前对所有候选文件执行文本审查及规则扫描，覆盖个人路径、私有案例标识、常见密钥格式、私钥、邮箱及网络地址。规则扫描不是对所有敏感信息的数学保证；后续贡献仍需要逐项审阅。

图纸处理脚本不主动发送参考图或结果到远程服务。依赖安装使用包索引；使用外部 AI agent 时，其数据处理由该工具自身设置决定。
